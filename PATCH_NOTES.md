# Kit-Start: набор исправлений

Этот архив содержит готовые версии файлов, которые нужно добавить или заменить в корне репозитория.

## Применение

Из корня локального репозитория распакуй архив с заменой файлов. Например:

```bash
unzip -o kit-start-fixes.zip -d .
chmod +x install.sh scripts/*.sh scripts/lib/*.sh tests/*.sh
make test
```

Архив включает только файлы, которые изменяются или добавляются. Неизменённые модули `scripts/cleanup.sh` и пустой `configs/zsh/.zshrc` в нём не нужны.

## Удалить из репозитория

```text
packages/backend.txt
packages/optional.txt
scripts/cleanup.sh
```

`backend.txt` был пустым; backend-компоненты ставятся отдельными модулями. `optional.txt` дублировал назначение `scripts/optional.sh`. `cleanup.sh` не вызывался ни одним профилем и не имел соответствующего install-функционала.

## Что исправлено

- `system.sh` теперь определяет `install_system()` и не выполняет команды при `source`.
- `docker.sh` устанавливает Docker Engine из официального APT-репозитория, Compose Plugin и Buildx.
- `database.sh` проверяет только клиенты PostgreSQL, Redis и SQLite.
- `cpp.sh` проверяет весь заявленный toolchain.
- `install.sh` предварительно загружает все модули и проверяет наличие ожидаемых функций до начала установки пакетов.
- Пакеты APT собраны в списки без повторной установки из модулей.
- Исправлены профили, Makefile, тесты и README.
- Удалены остатки настройки Go.
- Добавлены GitHub Actions, `.gitignore`, `.editorconfig`, `.shellcheckrc` и MIT LICENSE.

## Важно

Это статический набор исправлений. Полная установка не выполнялась в виртуальных машинах Ubuntu 22.04/24.04/26.04. После `make test` отдельно проверь установку в чистой VM каждой целевой версии Ubuntu. Для Docker дополнительно проверь доступность официального репозитория для конкретного codename.
